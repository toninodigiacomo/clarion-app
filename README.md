# Clarion — mode d'emploi

[Clarion](clarion.vektoriel.com) garde vos contrats et vos documents dans un **coffre chiffré dans votre navigateur**, surveille les délais de résiliation et vous aide à tenir votre budget. Le serveur ne voit jamais vos données en clair.

> Clarion analyse, il ne conseille pas.

## Trois choses à retenir

1. **Votre mot de passe protège vos données.** Personne, pas même l'administrateur, ne peut les lire ni les récupérer à votre place.
2. **Gardez votre clé de récupération et vos codes de secours** en lieu sûr, hors de Clarion (gestionnaire de mots de passe, papier dans un tiroir).
3. **Le budget et les lettres fonctionnent aussi sans compte**, entièrement dans votre navigateur.
