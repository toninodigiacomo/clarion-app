# 1. Premiers pas

## Obtenir un accès

Clarion fonctionne **sur invitation**.

- Vous avez reçu un e-mail d'invitation : cliquez sur le lien (valable **72 heures**).
- Sinon : page d'accueil → **Demander un accès**, laissez votre e-mail et un mot. L'administrateur vous enverra une invitation.

## Créer son compte

1. Choisissez votre **mot de passe maître** : au moins **12 caractères**, une majuscule, une minuscule, et un chiffre ou un caractère spécial. Une phrase de passe est idéale (« Ma voiture rouge date de 2019 ! »).
2. Cochez la case confirmant que vous avez compris : **sans ce mot de passe ni la clé de récupération, vos données sont perdues.**

## Activer la double authentification (obligatoire)

Un mot de passe seul peut être volé. Le second facteur est un code à 6 chiffres qui change toutes les 30 secondes, généré par votre téléphone.

1. Installez une application d'authentification : Google Authenticator, Microsoft Authenticator, Aegis, 2FAS, ou celle de votre gestionnaire de mots de passe.
2. Dans l'application : **+** → **Scanner un QR code**, et visez le code affiché à l'écran. (Pas d'appareil photo ? Saisissez la clé affichée sous le QR code.)
3. Tapez le code à 6 chiffres proposé par l'application.

## Sauvegarder ses clés de secours

Clarion affiche alors, **une seule fois** :

- la **clé de récupération** (8 groupes de 7 caractères) : elle remplace votre mot de passe si vous l'oubliez ;
- **10 codes de secours** : ils remplacent votre téléphone si vous le perdez (chaque code ne sert qu'une fois).

Copiez-les dans votre gestionnaire de mots de passe ou imprimez-les. Rangez-les **ailleurs** que sur votre téléphone.

Votre coffre est prêt, avec six collections : Mobilité, Logement, Santé, Prévoyance et épargne, Revenus et impôts, Divers.
