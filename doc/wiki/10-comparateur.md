# 10. Comparer à garanties égales

Une offre moins chère couvre-t-elle autant ? Menu **Comparer**. La grille aligne les offres **couverture par couverture** et signale les trous. Clarion analyse, il ne recommande pas.

## Sans compte : la grille manuelle

1. Choisissez le **type de contrat** (auto, ménage et RC, LAMal, LCA, vie, hypothèque).
2. Pour chaque offre (2 à 4) : le nom de l'assureur, la **prime** et sa périodicité, la franchise générale.
3. **+ Ajouter une couverture** : la ligne apparaît dans toutes les offres. Indiquez la somme assurée et la franchise ; retirez-la (×) dans l'offre qui ne l'inclut pas.
4. Cochez **Contrat actuel** sur votre contrat : les écarts de prix se calculent par rapport à lui.

Rien n'est envoyé ni conservé.

## Ce que la grille signale

| Signal | Signification |
|---|---|
| **absente** (rouge) | une autre offre inclut cette couverture, celle-ci non |
| **somme inférieure** (orange) | somme assurée plus basse que dans une autre offre |
| **franchise plus élevée** (orange) | vous paierez plus vous-même en cas de sinistre |
| −300 CHF par an | écart de prime annuelle avec le contrat actuel |

Une somme laissée vide (« n. p. », non précisée) n'est jamais signalée comme inférieure.

## Avec un compte

- **Depuis une fiche** : votre contrat actuel, avec ses couvertures. Le bouton **Comparer** de l'échéancier ouvre directement la grille avec le contrat concerné.
- **Depuis un PDF (IA)** : une offre reçue en PDF, déposée dans le coffre, lue par votre assistant IA (texte pseudonymisé, comme pour l'extraction d'une police). Vérifiez les montants : l'offre est marquée « à vérifier ».
- **Expliquer avec l'IA** : une synthèse factuelle de **pourquoi** les prix diffèrent (couverture en moins, franchise plus haute…). Seules les données de la grille sont envoyées, sans nom ni numéro de police. Ce n'est pas une recommandation.
- **Enregistrer** : la comparaison est chiffrée dans la collection choisie ; retrouvez-la dans **Mes comparaisons**.
