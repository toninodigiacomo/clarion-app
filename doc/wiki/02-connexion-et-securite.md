# 2. Connexion et sécurité

## Se connecter

1. **Se connecter** → e-mail et mot de passe maître.
2. Code à 6 chiffres de votre application d'authentification.

Votre mot de passe sert aussi à **déchiffrer le coffre dans votre navigateur** : il n'est jamais envoyé tel quel au serveur.

## Verrouillage automatique

- Après **15 minutes** sans activité, le coffre se verrouille : retapez votre mot de passe pour le rouvrir.
- Après **8 heures**, la session se termine : reconnectez-vous.
- Recharger la page verrouille aussi le coffre. C'est normal : les clés ne sont gardées qu'en mémoire.

## En cas de problème

| Situation | Solution |
|---|---|
| Téléphone perdu ou changé | À l'écran du code : **Je n'ai pas mon téléphone** → un code de secours. Puis, dans **Compte**, générez de nouveaux codes. |
| Plus de téléphone **et** plus de codes de secours | Demandez à l'administrateur de réinitialiser votre double authentification. Il n'a pas accès à vos données pour autant. Vous la réactiverez à la connexion suivante. |
| Mot de passe oublié | **Connexion → Mot de passe oublié** : e-mail, code de l'application, puis votre **clé de récupération** et un nouveau mot de passe. |
| Mot de passe **et** clé de récupération perdus | Les données ne peuvent pas être récupérées, par personne. C'est le prix du chiffrement de bout en bout. |

## Bonnes pratiques

- Un mot de passe maître **unique**, utilisé nulle part ailleurs.
- Ne vous connectez pas depuis un ordinateur public.
- Clarion ne vous demandera **jamais** votre mot de passe ou un code par e-mail ou par téléphone.
